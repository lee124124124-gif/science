# 과학 시뮬레이션 허브

학교 과학시간에 사용할 시뮬레이션(HTML 파일)을 업로드하고, 대시보드에서 미리보기를 보며 골라 바로 실행할 수 있는 웹앱입니다.
설치나 빌드, 백엔드 서버가 필요 없고 브라우저에서 바로 동작합니다.

## 실행 방법

```
powershell -ExecutionPolicy Bypass -File .\serve.ps1
```

서버 실행 후 브라우저에서 `http://localhost:8000` 으로 접속하세요.
(더블클릭으로 index.html을 직접 열면 브라우저에 따라 저장 기능(IndexedDB)이 제한될 수 있습니다.)

## 사용 방법

1. **업로드** — 오른쪽 위 "＋ 시뮬레이션 업로드" 버튼을 눌러 제목, 대상 학년(중/고), 설명, (선택)미리보기 이미지, HTML 파일을 등록합니다.
2. **탐색** — 대시보드의 "중학생" / "고등학생" 탭에서 카드로 시뮬레이션 목록을 확인합니다.
3. **실행** — 카드를 클릭하면 시뮬레이션이 전체 화면으로 실행됩니다.
4. **의견 남기기** — 실행 화면 오른쪽 패널에서 해당 시뮬레이션에 대한 건의사항이나 의견을 남기고, 이전에 남긴 의견도 함께 확인할 수 있습니다.
5. **삭제** — 실행 화면 상단의 "삭제" 버튼으로 잘못 올린 시뮬레이션을 지울 수 있습니다.

## 참고 / 제약사항

- 업로드한 시뮬레이션, 미리보기 이미지, 건의사항은 **브라우저의 IndexedDB에 저장**됩니다. 즉, 같은 브라우저/같은 기기에서만 보입니다. 다른 컴퓨터나 학생 개인 기기에서도 똑같이 보이게 하려면 별도의 서버/백엔드 연동이 필요합니다 (지금 구조는 교실 PC 한 대에 모아두고 프로젝터로 보여주는 용도에 적합합니다).
- 업로드는 **단일 .html 파일**만 지원합니다. 파일 안에서 CDN(인터넷) 스크립트를 불러오는 것은 가능하지만, 별도의 로컬 이미지/js/css 파일을 함께 올릴 수는 없습니다. (PhET, GeoGebra 등에서 "단일 HTML로 내보내기"한 파일과 잘 맞습니다.)
- 시뮬레이션은 `sandbox` 속성이 적용된 iframe에서 실행되어 대시보드 페이지와 분리됩니다.

## 파일 구조

```
index.html         # 대시보드 마크업 (탭, 카드 그리드, 업로드 모달, 실행 화면)
css/style.css       # 전체 스타일
js/db.js             # IndexedDB 저장소 (시뮬레이션, 건의사항)
js/app.js             # 탭 전환, 업로드, 실행, 건의사항 로직
serve.ps1                # Node/Python 없이 바로 쓸 수 있는 PowerShell 정적 서버
```
